# API NASA

Um projeto mobile que usa a API APOD da NASA

# Integrantes:

 * Henrique Kenji

# Descrição: 

este projeto tem com objetivo mostrar a imagem do dia contendo um título, data, descrição e também com a possibilidade de pesquisar uma imagem da api da NASA
